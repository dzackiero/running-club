# Personal Dashboard Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove every clubs feature and make the existing app open as a personal Today dashboard without losing runs, users, goals, or integrations.

**Architecture:** Delete club types, database declarations, HTTP routes/services/jobs, UI pages, and all call sites. Preserve the current run and weekly-goal APIs as the initial source for Today; the second plan adds the unified plan data. Use a generated Drizzle migration to drop only club tables.

**Tech Stack:** TypeScript, pnpm, Hono, Drizzle ORM/Postgres, React/Vite, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-18-personal-training-dashboard-design.md`

## Global Constraints

- Club data deletion is intentional and irreversible; only `club`, `club_member`, `club_nudge`, and `club_period_result` may be dropped.
- Do not change existing users, sessions, runs, weekly goals, preferences, or Intervals integration records.
- Every authenticated API route continues to enforce `requireUser` and every service scopes records by `userId`.
- Use `pnpm` and Node.js 22+; do not add dependencies for this phase.
